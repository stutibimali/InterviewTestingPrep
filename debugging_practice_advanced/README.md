# Advanced Debugging Practice

This is a debugging-focused prep pack meant to match a live technical interview.

The goal is to debug real Python functions and FastAPI logic, not to answer theory questions.

## How to use it

1. Read the failing tests.
2. Fix the bugs in the implementation files.
3. Run the smallest relevant pytest command.
4. Explain each fix clearly as if speaking to the interviewer.

## Focus areas

- falsey values and `None`
- list parsing and whitespace cleanup
- off-by-one errors
- FastAPI auth/header validation
- data normalization and filtering
- edge-case reasoning
